# Instagram Downloader

A simple Instagram Reels, Videos, Photos, and Story Downloader built with HTML, CSS, JavaScript, Node.js, Express, and RapidAPI.

## Features

- Download Instagram Reels
- Download Instagram Videos
- Preview videos before downloading
- Direct download button
- Responsive UI
- RapidAPI integration
- Deployed on Render

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- RapidAPI
- Render
- GitHub

## Installation

Clone the repository:

```bash
git clone https://github.com/thakurshab-dev/instagram-downloader.git
```

Go to project folder:

```bash
cd instagram-downloader
```

Install dependencies:

```bash
npm install
```

Create a `.env` file:

```env
RAPIDAPI_KEY=YOUR_RAPIDAPI_KEY
```

Start the server:

```bash
node server.js
```

Open:

```text
http://localhost:3000
```

## Environment Variables

Required:

```env
RAPIDAPI_KEY=YOUR_RAPIDAPI_KEY
```
